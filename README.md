# マモルマヌーの「今日のラッキーカラー」LINE Bot

お金の仕組みなし・AIなし・ライブラリなし。いちばん簡単な形です。

## できること
- ファンが何か一言（「おはよう」など）を送ると、**今日のラッキーカラー**のカードが届きます。
- カードには、お兄さんの写真・日付・色・ひとことが入ります。
- **色も写真も、毎日変わります。** 日本時間の0時に切りかわります。
- **その日は、全員が同じ色**です（「今日はみんな同じ色だね」という話題になります）。
- 色は14色。一周するまで、同じ色は出ません（毎回ちがう順番です）。
- 友だち追加すると、あいさつと、今日のカードが届きます。

## 写真を増やす
`photos` フォルダに、写真を入れるだけです。入れた枚数だけ、毎日ちがう写真が出ます。
- 今入っている5枚は、**ハート形の額縁**に入れた、背景が透明の画像（png）です。カードでは、その日のラッキーカラーが背景になります。
- 新しい写真を足すときは、ここに写真を送ってもらえれば、同じハート形に整えます。
- 自分で入れる場合は、正方形（800px前後）で、1枚1MB以下のpngかjpgにしてください。
- GitHubの `photos` フォルダに、アップロードして保存すれば、Renderが自動で更新します。

## 色や文字を変える
`colors.mjs` を開いて、色の名前・色・ひとことを書き換えるだけです。

## 用意するもの（1回だけ）
1. **LINE Developers** で、新しい「Messaging API」のチャネルを作る（他のBotとは別です）。
   「Channel secret」と「Channel access token（長期）」をメモします。
2. **GitHub** に、新しいリポジトリを作って、このフォルダの中身（`photos` も）をアップロードする。
3. **Render** で、「New → Web Service」を選び、そのリポジトリをつなぐ。
   - Start Command：`npm start`
   - Environment に次の2つを入れます。
     - `LINE_CHANNEL_SECRET` = メモしたChannel secret
     - `LINE_CHANNEL_ACCESS_TOKEN` = メモしたChannel access token
   - （任意）カードの下に、ボタンを出したいとき
     - `LINK_LABEL` = ボタンの文字（例：兄の動画を見る）
     - `LINK_URL` = 行き先（例：YouTubeのチャンネルのURL）
     - ※ 将来、お店や商品のページに変えたいときも、ここを変えるだけです。
   - 写真が表示されないときだけ：`PUBLIC_URL` = RenderのURL（例：https://xxxx.onrender.com）
4. Renderで公開URLが出たら、LINE Developersの「Webhook URL」に `https://（RenderのURL）/webhook` を入れて、「Use webhook」をオンにし、「Verify」を押す。
5. LINE Official Account Managerで、「あいさつメッセージ」と「応答メッセージ」は、オフにします。

## 動作確認
- ブラウザで、RenderのURLを開いて「OK」と出れば、動いています。
- ブラウザで `（RenderのURL）/photos/mamoru-01.jpg` を開いて、写真が出れば、写真の準備もOKです。
- `npm test` で、中身のテストができます（Node.jsがある場合）。

## 注意
- Renderの無料プランは、しばらく使われないと眠るため、最初の返事が遅れることがあります。
- 写真は、ご家族の写真です。第三者が写っている写真は、避けてください。
